# Changelog

## [UNRELEASED]

- Manual `Indent using spaces` now works as expected.
- Added a FAQ section about how to turn off the plugin for a single file.

## 0.2.0, 2026-11-27

- Fixed `Backspace` so it can delete tab characters on an empty line.
- Smart Tab no longer overrides default configurations.
- Add documentation of how to enable Smart Tab globally or for a specific repository.
- Empty lines will no longer be indented on `Tab` when multiple lines are selected.

## 0.1.0, 2026-11-26

- Initial release: `Tab` and `Shift+Tab` adjust leading indentation and pack it into tabs and spaces.
